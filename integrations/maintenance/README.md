# Режим реконструкции

Отдельный PHP-шлюз. Исходный сайт и экспорт `out` не изменяются.

Корень сайта в Plesk: `storex.kz/integrations/maintenance/public`.
В Apache/nginx отключить прямую и интеллектуальную обработку статических файлов nginx: все защищённые URL проходят через PHP.

Вне корня сайта, в `private/storex-maintenance.php`, разместить PHP-массив с `username` и `password_hash` (результат `password_hash` с PASSWORD_DEFAULT). Этот файл никогда не хранить в Git. Права 0600. Исходный пароль не хранится.

Сессия: Secure, HttpOnly, SameSite=Strict, cookie __Host-storex_dev. Новая сессия после входа, таймаут бездействия 30 минут, абсолютный срок 8 часов. CSRF и ограничение попыток на сервере. Выход: открыть `/__developer/login` и нажать «Выйти». Ответы сайта не кэшируются.

Для отключения режима вернуть корень сайта в Plesk на `storex.kz/out`. Файлы исходного сайта, почта, CAPTCHA и Git-развёртывание не меняются.
