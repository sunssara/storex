Обработка данных

Для защиты формы от автоматических отправок используется Cloudflare Turnstile. При загрузке проверки сервис получает технические данные браузера и сетевого подключения для проверки на спам.

Форма предназначена для обращения в ТОО «STOREX» по вопросам проектов и услуг. Мы запрашиваем имя, компанию, email, описание задачи и, по желанию, телефон.

Эти сведения передаются через почтовый сервис Resend на info@storex.kz для рассмотрения обращения и связи с вами. Указывайте только информацию, необходимую для обсуждения задачи; не отправляйте пароли или конфиденциальные документы.

На сайте нет регистрации, базы заявок или рекламных трекеров. Обращение сохраняется в почтовой системе получателя. По вопросам обработки или удаления данных пишите на info@storex.kz.
